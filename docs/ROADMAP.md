# Roadmap theo cổng nghiệm thu

## Gate 0 — Foundation

- CI xanh, image pin, staging/backup/restore.
- Gateway security baseline và contract versioning.
- Capability registry, policy, approval, audit ledger PostgreSQL.

## Gate 1 — Core Việt Nam

- VNDIRECT/SSI/VPS/TCBS fixture đã ẩn danh.
- Reconciliation phí/thuế/P&L với báo cáo broker.
- Import trong trình duyệt, journal và dashboard mới.
- 20 người thử; tối thiểu 60% hoàn tất import hợp lệ.

## Gate 2 — Paid MVP

- Thanh toán phù hợp khách hàng mục tiêu.
- Quota/entitlement, export, delete account/data.
- Monitoring, support workflow và chính sách riêng tư.

## Gate 3 — Hub

- Tool manifest, review, tagging, search và analytics sử dụng.
- Watchlist/scanner/news Việt Nam qua provider có quyền sử dụng dữ liệu.
- Blog/SEO không có quyền truy cập dữ liệu giao dịch.

## Gate 4 — AI

- Journal coach có evidence và giới hạn chi phí.
- AI provider adapter, prompt/version/eval registry.
- Vibe-Trading worker cô lập cho research/backtest.
- Không auto-trading; mọi capability write/execute cần phê duyệt riêng.
